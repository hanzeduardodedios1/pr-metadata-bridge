# CaptionFast Product Roadmap

| Version | Feature | Description | Value | Effort |
|---------|---------|-------------|-------|--------|
| V1.1 | Native Multi-Select | Add Shift-Click and Ctrl-Click for rapid photo batching. | High | Low |
| V1.1 | Session Tagged Badge | Visual green checkmark overlay for files processed in the current session. | High | Low |
| V1.2 | VIP Priority Flagging | Let users upload a .txt list of the client's C-Suite executives. If the OCR scans a name on that list, apply a special XMP:Rating. | High | Med |
| V1.2 | Drag-to-Lasso Select | Click-and-drag a bounding box to select multiple thumbnails at once. | Med | Med |
| V1.3 | CSV Roster Export | Generate a simple .csv file mapping the image filenames to the scanned names alongside the IPTC injection. | Med | Low |
| V2.0 | Auto-Advance Engine | Once a batch is processed, automatically jump to the next unprocessed photo containing a badge. | High | High |
| V2.0 | Multi-Folder Queue | Allow loading Day 1, Day 2, and Day 3 folders simultaneously, processing ExifTool writes in the background. | High | High |
